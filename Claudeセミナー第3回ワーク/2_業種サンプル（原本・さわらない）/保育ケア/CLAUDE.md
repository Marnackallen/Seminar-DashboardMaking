# このフォルダの作業ルール

このフォルダは、経営者向け研修で使う「業務ダッシュボード」です。
使う人はプログラマーではありません。説明は短く、専門用語を避けてください。

## 画面のしくみ

- `index.html` をダブルクリックで開き、「ファイルを選ぶ」で `data/` の3つのCSVを選ぶと表示されます。
- `lib/dashboard.js` がCSVを読み、`data.kaikei`・`data.nippo`・`data.nyukin` に行の配列として入れます。
  - 会計 `kaikei.csv`：日付／区分（売上・費用）／勘定科目／カテゴリ／摘要／金額（2025年1〜12月）
  - 日報 `nippo.csv`：日付／担当者／案件／予定時間／実績時間／所感（2025年12月・平日20日）
  - 入金 `nyukin.csv`：案件／請求内容／請求額／入金予定日／入金日（入金日が空欄＝未入金）
- 画面の部品（パーツ）は `parts/` に1つずつ別ファイルで置き、`Dashboard.addPart({...})` で登録します。
- グラフは `lib/chart.js` の関数（`MiniChart.groupedBar`・`line`・`hbar`・`table`・`tiles`）か、SVGとHTMLで描きます。

## 守ること

1. 既存のパーツ（`parts/part1〜3`）、`lib/`、`data/` の中身は変更しない。
   - ただし、使う人が既存パーツの修正をはっきり頼んだときは、頼まれた箇所だけ直してよい。
2. 新しいパーツは `parts/` に新しいファイルで作る。
   - 空き枠①に置くときは `slot: "slot1"`、空き枠②に置くときは `slot: "slot2"`。
   - `index.html` の「▼ 空き枠①（または②）のパーツは、この下に1行足す」のすぐ下に、`<script src="parts/新しいファイル名.js"></script>` を1行だけ足す。
   - `index.html` のそれ以外の部分は変えない。
3. 外部のライブラリ、CDN、インターネット接続を使わない（会場のネットが不安定なため）。
4. 表示は日本語。金額は円・3桁区切り、時間は小数1桁に「時間」、割合は小数1桁に「%」。
5. データにない数字は作らない。足りないときは、作る前に使う人に質問する。
6. ファイルを削除しない。

## 所感の読み方

- 注意語は次の10語：遅れ／遅延／不安／懸念／変更／キャンセル／未定／負担／疲れ／クレーム
- 数えるときは「語の出現回数」ではなく「注意語を1つ以上含む所感の件数」で数える。
- 所感が空欄の行は、表では「記入なし」と表示する。

## 作業が終わったら

使う人に、次の2つを短く伝える。
- ブラウザで `index.html` を再読み込みし、「ファイルを選ぶ」で3つのCSVを選び直すこと
- 何を足したか（ファイル名と、画面のどこに出るか）
