Claudeセミナー 第3回　業務ダッシュボードを1枚つくる
======================================================

このフォルダの中だけで、今日の作業をします。

  1_練習/                       ワーク1で使います（kaikei.csv だけが入っています）
  2_業種サンプル（原本・さわらない）/   4つの業種の土台です。ここは開かないでください
  3_作業/                       ワーク2で使います（最初は空です）


■ 約束（3つ）

 1. Claude Code（Code タブ）で開くのは、「1_練習」か「3_作業」の中のフォルダだけ。
    このフォルダ全体や、デスクトップは開かないでください。
 2. 「2_業種サンプル」は原本です。自分の業種のフォルダを「3_作業」にコピーして使います。
    ドラッグではなく、右クリック →「コピー」→「3_作業」の中で右クリック →「貼り付け」。
 3. 壊れたら、「3_作業」の中のフォルダの名前を「〇〇_失敗1」に変えて、
    原本からもう一度コピーします。消さなくて大丈夫です。


■ ワーク1　ゼロから1枚（1_練習）

 1. Code タブで「1_練習」を開く
 2. 講師がお配りするお題カードの指示①を貼る → 画面ができたら指示②
 3. 数字を1つ確かめる（12月の売上／10月の利益）


■ ワーク2　土台に足す（3_作業）

 1. 自分に近い業種のフォルダを「3_作業」にコピーする
       現場工程 …… 建設・製造
       専門サービス … コンサル・士業・研修
       店舗予約 …… 飲食・整体・サロン・貸衣装
       保育ケア …… 保育・介護
    ※ 4つとも数字は同じです。名前と文面だけが違います。近いもので十分です。
 2. コピーした方の index.html をダブルクリック →「ファイルを選ぶ」→ data の3つのCSVを選ぶ
 3. Code タブで、「3_作業」の中の業種フォルダを開く
 4. まず1か所だけ直す → 空き枠①に足す → 再読み込みしてCSVを選び直す → 数字を1つ確かめる
 5. 空き枠②に「自社で見たい数字」を足す


■ 困ったら

 手を挙げてください。メンターが伺います。
 承認の確認で、見慣れない操作が出てきたときも、承認せずに手を挙げてください。

 ※ このフォルダのデータはすべて架空です。実在の会社・人物とは関係ありません。
